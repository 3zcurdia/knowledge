# Knowledge Base

Personal markdown knowledge base. Captures, organizes, and cross-references knowledge from conversations, articles, and observations.

## Structure

| Directory | Purpose |
|-----------|---------|
| `captures/` | External knowledge — numbers, observations, patterns |
| `decisions/` | Decision records and trade-offs |
| `notes/` | General reference |
| `projects/` | Project-specific knowledge and prompt templates |
| `inbox/` | Unprocessed items (chats, articles, agent output) |

## Skills

- `/process-inbox` — triage inbox items into the categorized KB
- `/consolidate` — find duplicates, merge overlaps, add cross-references
