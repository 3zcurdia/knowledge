# Programming Language Syntax Comparison Resources

## Primary Resources

- <https://learnxinyminutes.com/> — Single-file language overviews with comments.
  Best for learning a new language when you already know one.
- <https://rosettacode.org/> — Same programming task implemented in hundreds of
  languages. Largest collection of idiomatic algorithm implementations.
- <https://hyperpolyglot.org/> — Side-by-side reference sheets (C vs Rust, Python vs
  JS, etc.). Designed for "I know X, show me Y."
- <https://programiz.com/> — Beginner-friendly tutorials with good UI.

## Reference & Cheat Sheets

- <https://devdocs.io/> — Unified documentation browser for many languages and
  frameworks.
- <https://devhints.io/> — Nice-looking cheat sheets per language.
- <https://quickref.me/> — Modern interface, lots of language cheat sheets.
- <https://overapi.com/> — Aggregates cheat sheets for many languages.
- <https://cheatsheets.zip/> — Concise cheat sheets for languages and tools.

## Interactive

- <https://replit.com/> — Run code in dozens of languages directly in the browser.
- <https://exercism.org/> — Same exercises in many languages; good for comparing
  idiomatic solutions.

## Usage Pattern

- **"How do I write X in different languages?"** → Rosetta Code
- **"I know C, show me Swift"** → Hyperpolyglot or Learn X in Y Minutes
- **"Compare algorithm implementations"** → Rosetta Code (open two tabs)
- **No single site offers a polished side-by-side syntax and algorithm comparison
  across all languages** — this is a known gap in developer tooling.
