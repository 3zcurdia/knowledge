# Refurbished ThinkCentre and ThinkPad Buying Guide

A practical guide for buying refurbished Lenovo ThinkCentre Tiny desktops and
ThinkPad laptops for office work, covering both Windows and Linux use.

## Windows 11 Minimum

| Intel | 8th Gen or newer (e.g., i5-8250U, i5-8500T) |
| AMD   | Ryzen 2000 (Zen+) or newer                   |

Older hardware (Intel 7th Gen and below) lacks official Windows 11 support.

## Recommended Specs

- **RAM**: 16 GB minimum; 32 GB ideal. Avoid soldered RAM where upgrades matter.
- **SSD**: NVMe SSD, 512 GB minimum. Avoid SATA-only unless price is very
  attractive.

## Linux-Specific Recommendations

When Windows 11 support is not required, Linux opens up more budget options:

### Budget Champions (Intel 6th/7th Gen)

- ThinkCentre M700 Tiny / M710q Tiny
- ThinkPad T460 / T470
- Intel graphics, Wi-Fi, NVMe, suspend/resume all well-supported

### Sweet Spot ($150–300)

- **ThinkCentre M720q Tiny**: Quad-core, PCIe expansion, 2 RAM slots
- **ThinkCentre M920q Tiny**: Better build and expansion
- **ThinkPad T480**: Arguably the most famous Linux ThinkPad — dual RAM slots,
  replaceable SSD/Wi-Fi, Thunderbolt, USB-C charging

### Performance Sweet Spot ($250–450)

- **ThinkCentre M75q Gen 2** (Ryzen 5650GE): 6C/12T, very quiet, excellent
  AMDGPU support
- **ThinkPad T14 AMD Gen 1/2** (Ryzen 4650U / 5650U): Great battery, Linux
  compatibility

## Intel vs AMD for Linux

- **Older Intel (6th–10th Gen)**: Excellent compatibility, very stable
- **Modern AMD (Ryzen 4000+)**: Better graphics, multicore performance, efficiency,
  excellent open-source drivers. Generally preferred for Linux desktop use today.
